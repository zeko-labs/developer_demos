# Agent Skills Pack: Proof Over Hype

This folder contains reusable agent skills extracted from the Zeko testnet implementation and debugging cycle for:

- Auro wallet transaction signing
- o1js zkApp submission flows
- Merkle-root anchoring and historical proof verification
- Public demo safety controls (BYOK + limits)

## Included skills

1. `zeko-non-magic-fee-payer`
2. `auro-zkapp-preflight`
3. `zkapp-redeploy-consistency`
4. `image-canonicalization-verifier`
5. `historical-proof-verifier`
6. `secure-demo-packager`

Each skill is intentionally concise and operational, with explicit trigger criteria, procedure, validation checks, and failure signatures.
